# 视频生成 Beta 模块后端技术方案

## 1. 模块目标

视频生成 Beta 模块用于承接图片到商品展示视频的轻量生成能力，定位为第一版扩展功能，不是平台首个必须闭环。

## 2. 第一版定位

根据范围文档，本模块属于 Beta：

- 有入口
- 有任务模型
- 可限量开放
- 可使用单独模板或供应商
- 不应影响核心图片生成链路稳定性

## 3. 后端职责

- 管理视频模板配置
- 接收视频生成任务
- 根据模板和参数生成报价
- 走独立或共享任务队列
- 保存视频结果与封面

## 4. 接口建议

- `GET /api/v1/templates?type=video`
- `POST /api/v1/tasks/estimate`
- `POST /api/v1/tasks`
- `GET /api/v1/tasks/{id}`

本模块不需要单独另起一套任务接口，应复用统一任务域，只是在 `task_type=video` 下走专门参数校验与供应商适配。

## 5. 数据依赖

- `generation_templates`
- `generation_tasks`
- `task_outputs`
- `provider_task_records`

素材侧还要补充：

- 视频时长
- 分辨率
- 封面图

## 6. 实现策略

第一版建议：

- 复用统一任务域
- 单独定义 `video` 参数 DTO
- 单独定义视频供应商 adapter
- 单独配置视频计价规则

不建议：

- 为视频再拆一套独立系统

## 7. 风险点

- 视频生成耗时长
- 成本高
- 失败率可能高于图片

应对方式：

- 默认低并发
- 排队和超时策略单独配置
- 可通过白名单、套餐权限或 Beta 开关控制开放范围

## 8. 模块结论

视频生成 Beta 应作为统一任务域的一个任务类型扩展，而不是独立系统。第一版重点是“可运行、可限流、可计费、可回退”。
