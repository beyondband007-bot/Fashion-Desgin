# 创意生图 Beta 模块后端技术方案

## 1. 模块目标

创意生图 Beta 面向品牌调性探索和创意视觉快速产出，定位为第一版扩展生成能力。

## 2. 模块定位

与 AI 在线生成工作台相比，本模块的特点是：

- 更偏创意模板驱动
- 对模特、场景依赖较弱或可选
- 参数组合更开放
- 更适合模板化和预设化

## 3. 后端职责

- 管理创意模板
- 提供模板参数约束
- 计算创意任务报价
- 生成创意任务
- 保存输出结果

## 4. 接口建议

- `GET /api/v1/templates?type=creative`
- `GET /api/v1/templates/{id}`
- `POST /api/v1/tasks/estimate`
- `POST /api/v1/tasks`
- `GET /api/v1/tasks/{id}`

## 5. 数据模型依赖

- `generation_templates`
- `generation_tasks`
- `task_inputs`
- `task_outputs`

模板建议保存：

- 模板类型
- 预设参数 schema
- 示例图
- 是否上线

## 6. 技术实现原则

- 复用统一任务域和统一积分域
- 创意模板驱动，不要把模板逻辑写死在前端
- 模板参数校验在后端完成

## 7. 风险点

- 创意参数过于自由会导致供应商适配难
- 产出稳定性可能不如标准商品图

建议第一版策略：

- 只开放少量模板
- 参数收窄
- 使用模板版本号，避免前后端参数漂移

## 8. 模块结论

创意生图 Beta 第一版应做成“模板受控的生成任务扩展”，优先保证参数收口、供应商可适配、计费可解释。
