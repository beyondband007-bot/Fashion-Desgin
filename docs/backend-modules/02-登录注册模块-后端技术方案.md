# 登录注册模块后端技术方案

## 1. 模块目标

登录注册模块负责提供统一身份入口，支撑：

- 手机验证码登录
- 手机号密码登录
- 用户注册
- Token 刷新
- 退出登录
- 重置密码

该模块同时承担新用户账户创建与积分账户初始化的起点职责。

## 2. 第一版范围

第一版必须支持：

- 发送短信验证码
- 注册
- 验证码登录
- 密码登录
- Refresh Token
- 退出登录
- 重置密码
- 当前用户信息查询

第一版可预留：

- 微信扫码登录
- 企业账号登录
- 多端设备管理增强

## 3. 前端现状分析

当前前端已落地：

- 登录页 `/login`
- 注册页 `/register`
- 本地 `authStore`

但当前仅是演示登录态，未接真实后端。说明第一批真实接口必须优先打通本模块。

## 4. 后端职责

- 用户注册与认证
- 会话管理
- Token 签发与续期
- 验证码风控
- 密码安全校验
- 登录审计
- 注册后积分账户创建与新手赠送触发

## 5. 核心接口

- `POST /api/v1/auth/sms/send`
- `POST /api/v1/auth/register`
- `POST /api/v1/auth/login/password`
- `POST /api/v1/auth/login/sms`
- `POST /api/v1/auth/token/refresh`
- `POST /api/v1/auth/logout`
- `POST /api/v1/auth/password/reset`
- `GET /api/v1/users/me`

## 6. 关键数据表

业务库：

- `users`
- `auth_sessions`
- `verification_codes`
- `password_history`
- `user_oauth_bindings`

跨库联动：

- 注册成功后调用积分服务创建 `credit_account`
- 触发注册赠送积分

## 7. 关键流程

### 7.1 注册流程

1. 校验手机号、验证码、密码强度。
2. 幂等创建用户。
3. 写入密码历史。
4. 创建默认会话。
5. 调用积分服务创建账户。
6. 调用积分服务发放新手积分。
7. 返回用户信息和 Token。

### 7.2 登录流程

1. 校验账号和凭证。
2. 检查用户状态。
3. 创建新会话并签发 Token。
4. 记录 `last_login_at`、`ip`、`user_agent`。

## 8. 安全方案

- 密码使用 Argon2id
- 手机号落库加密，查询走 hash
- 验证码写 Redis，DB 留审计痕迹
- 短时间登录失败限流
- Refresh Token 只存 hash

## 9. 风险点

- 重复注册导致积分重复赠送
- 验证码接口被刷
- Refresh Token 重放

解决方式：

- 写接口强制幂等
- 验证码和登录限流
- 会话级 Refresh Token 轮换

## 10. 模块结论

登录注册模块是第一版所有后续业务的入口，应作为后端 P0 模块优先实现，并率先完成前后端联调。
