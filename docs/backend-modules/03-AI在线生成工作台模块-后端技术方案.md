# AI 在线生成工作台模块后端技术方案

## 1. 模块目标

AI 在线生成工作台是平台第一版最核心的业务模块，承担：

- 衣服图生成
- 真人图生成
- 人台图生成
- AI 模特替换

其本质是“素材上传 + 参数配置 + 任务报价 + 任务创建 + 异步执行 + 结果回传 + 积分结算”的闭环。

## 2. 第一版范围

第一版必须支持：

- 模特列表查询
- 场景列表查询
- 任务报价
- 任务创建
- 任务进度推送
- 最近结果查询
- 取消任务
- 重试任务
- 下载结果

不包含：

- AI 编辑 2.0 工具箱
- 复杂画布式编辑

## 3. 前端现状分析

当前前端 `AiGeneratePage` 已经具备完整工作台交互：

- 上传素材
- 选择模特
- 选择场景
- 配置输出参数
- 预估积分
- 生成
- 查看最近结果
- 预览对比

但当前生成、进度、扣积分都还是本地模拟，说明后端要接管这个页面的大部分关键状态。

## 4. 后端职责

- 校验任务参数与素材归属
- 计算积分报价
- 创建任务和账务冻结
- 进入 AI 队列
- 供应商提交、回调和状态同步
- 保存输出素材
- 成功结算 / 失败退款
- 推送任务进度

## 5. 核心接口

- `GET /api/v1/models`
- `GET /api/v1/scenes`
- `POST /api/v1/tasks/estimate`
- `POST /api/v1/tasks`
- `GET /api/v1/tasks`
- `GET /api/v1/tasks/{id}`
- `POST /api/v1/tasks/{id}/cancel`
- `POST /api/v1/tasks/{id}/retry`
- `POST /api/v1/tasks/{id}/download`
- `POST /api/v1/realtime/token`
- `GET /api/v1/ws?token=...`

## 6. 关键数据表

- `task_quotes`
- `generation_tasks`
- `task_inputs`
- `task_outputs`
- `task_attempts`
- `provider_task_records`
- `task_events`

依赖的基础表：

- `assets`
- `ai_models`
- `scenes`
- `credit_pricing_rules`

## 7. 核心流程

### 7.1 报价流程

1. 读取套餐与计价规则。
2. 根据任务类型、输出张数、质量参数计算预估积分。
3. 写入 `task_quotes`。
4. 返回 5 分钟有效报价。

### 7.2 创建任务流程

1. 校验报价、归属和权限。
2. 创建 `generation_task`，状态 `billing_pending`。
3. 调用积分服务冻结积分。
4. 冻结成功后任务入队。
5. Worker 调用 AI 供应商。

### 7.3 完成流程

1. 接收回调或轮询结果。
2. 保存结果素材。
3. 更新任务状态为 `completed`。
4. 调用积分服务结算。
5. 通过 WebSocket 推送完成事件。

## 8. 实时方案

建议使用 WebSocket：

- 工作台需要持续进度反馈
- 项目页也会复用任务状态事件
- 相比轮询更节省前端复杂度

事件建议：

- `task.created`
- `task.updated`
- `task.completed`
- `task.failed`
- `task.refunded`

## 9. 风险与控制

- 供应商重复回调：必须幂等
- 任务失败未退款：必须补偿
- 前端重复点击创建：必须依赖 `Idempotency-Key`
- 并发超限：后端按套餐并发额度拦截

## 10. 模块结论

该模块是第一版的核心后端模块，应在认证、上传基础能力就绪后最优先开发。没有这个模块，就没有平台真正的业务闭环。
