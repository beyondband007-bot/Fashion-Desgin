# 前端只读接口接入第一轮 - 开发归纳

## 1. 本轮目标

本轮目标不是把整站前端全部改成真实接口，而是先完成第一批最有价值的只读接口替换，让页面开始脱离 `mockService`。

优先接入页面：

- AI 工作台
- 素材管理
- 我的项目
- 套餐 / 积分
- 积分查询

## 6. 下一步建议

下一步建议按下面顺序继续，不要扩散：

1. 把 AI 工作台的 `estimate / create / tasks` 接上真实接口
2. 再接 WebSocket 单连接实时同步
3. 然后补任务详情、事件流、取消、重试、下载
4. 最后再决定是否给企业版、创意页补新接口

## 7. 结论

本轮已经完成“前端读接口替换第一轮”，页面开始具备基于真实后端做联调的条件。  
接下来最值得继续推进的，不是再补更多静态读取，而是把 AI 工作台真正切进任务创建与实时状态链路。
