# 前端现状对齐只读接口模块 - 开发归纳

## 1. 本轮开发目标

本轮不是继续扩任务写链路，而是对齐当前前端实际已存在页面，把仍依赖 `mockService` 的主要只读能力补到后端。

重点覆盖：

- 素材页
- 项目页
- 套餐页
- 积分流水页
- AI 工作台模型 / 场景 / 最近结果的前端兼容字段

## 3. 关键实现说明

### 3.1 双库读取策略

- 素材、项目：读 `fashion_biz`
- 积分流水：读 `fashion_ledger`
- 套餐：当前静态返回

### 3.2 fallback 策略

若数据库当前为空：

- 素材列表返回 fallback
- 项目列表返回 fallback
- 积分流水返回 fallback
- 套餐列表始终可返回静态目录

这样做的目的，是不让前端联调被“当前库里没数据”阻塞。

### 3.3 前端兼容字段策略

本轮采用“双字段并存”：

- 保留后端标准字段
- 增补前端当前直接使用的 camelCase / 简化字段

这样前端后续可以先快速切接口，再决定是否统一做字段适配层。
