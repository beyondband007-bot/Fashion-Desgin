# 19-AI生成页任务接口闭环接入-开发归纳

## 1. 本轮目标

在前端 `AI 生成` 页面已有工作台交互基础上，补齐“任务接口 + WebSocket 状态回流 + 本地兜底”的实际闭环，确保页面点击“生成”后不只是本地动画，而是优先走真实后端任务链路。

本轮目标包含：

- 前端点击“生成”先调用后端任务估价接口
- 然后调用任务创建接口
- 创建成功后通过既有 WebSocket 主连接接收任务状态变化
- 页面预览区根据全局任务中心中的任务状态自动回流更新
- 后端不可用时回退到本地 mock，保证开发不断线

## 4. 当前页面行为

在 `AI 生成` 页面点击“生成”后：

1. 页面进入 `pending`
2. 前端向后端发起估价
3. 前端向后端创建任务
4. 后端创建任务并通过 WebSocket 广播
5. 前端全局任务中心收到任务事件
6. 页面根据 `activeTaskId` 回流展示进度与阶段
7. 任务完成后展示结果图并写入最近结果

## 5. 当前边界

本轮仍然保持“开发联调版”边界：

- 不处理用户数据权限
- 不处理多租户隔离
- 不处理真实文件上传与真实素材资产 ID
- 当前 `input_asset_ids` 仍是前端本地占位 ID
- 当前任务状态推进仍由前端主动调用状态接口模拟
